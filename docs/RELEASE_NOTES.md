# Release notes
## v0.2 — prepared release
Allows up to four different exosuits in the existing four slots. Four selected exosuits were deployed and reported working on the supported build on September 20, 2026.
The release preparation adds artwork, manager metadata, a generated file manifest and portable source/build documentation. Gameplay archive bytes are unchanged from the successful v0.2 test. Internal runtime/log labels retain `0.2-data-experimental` to preserve those validated bytes.
Requires Bingus Shared Loader v15 / API 1, obtained separately. Redistribution terms for the reused adapter remain pending; see THIRD_PARTY.md.

Earlier executable patch experiment. Not included or recommended for installation.
